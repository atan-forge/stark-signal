# Security Policy

Do not include recordings, filenames, URIs, paths, transcript content, or model files in a public issue.

For ordinary product support, use the [Stark Signal issue tracker](https://github.com/atan-forge/stark-signal/issues). Do not use public issues to report a suspected security vulnerability.

For security reports, use the repository's private vulnerability reporting form in GitHub Security Advisories. The project maintainer enables that GitHub feature for official public releases.

Supported official releases are those signed by Atan Forge's published signing certificate. Forks and modified builds are not official Stark Signal releases.

The project rejects dependencies or changes that silently add networking, analytics, advertising, broad storage access, WebView content, or unreviewed native code.
