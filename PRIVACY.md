# Privacy Notice

Last updated: 2026-08-21

Stark Signal processes recordings, imported media, prepared audio, and transcripts on the Android device. The application does not declare Android's Internet permission and contains no account system, analytics, advertising, cloud storage, or remote transcription.

## Data handled

The app handles microphone audio when the user starts recording, local media selected or shared by the user, generated audio outputs, transcripts, waveform metadata, job state, and privacy settings. These remain in app-private storage unless the user explicitly saves or shares a copy.

## Permissions

Microphone access is used only for visible recording. Foreground-service permissions keep an active user-started recording reliable when the screen is off or another app is visible. Notification permission enables recording controls. Biometric permission is used only when the optional app lock is enabled.

## Storage and deletion

Private-vault data is excluded from Android cloud backup and device transfer. Uninstalling the app removes unexported vault content. Individual recordings, prepared outputs, and transcripts can be deleted independently.

## Sharing

The app shares only after an explicit user action and uses temporary content URI access. The destination app controls data after the user shares it.
